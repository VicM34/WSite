# 🛒 Веб-приложение "AstroStore"

## 📋 Описание проекта

Простое веб-приложение для интернет-магазина, разработанное в рамках учебного задания. Приложение включает 4 адаптивные HTML-страницы с использованием Bootstrap 5.3 и реализует базовый HTTP-сервер на стандартной библиотеке Python.

## ✨ Ключевые особенности

✅ **4 готовые HTML-страницы** с адаптивным дизайном  
✅ **Bootstrap 5.3** через CDN  
✅ **Веб-сервер** на базе `http.server`  
✅ **Обработка GET/POST** запросов
✅ **Адаптивность** для мобильных устройств

## 📁 Структура проекта

| Папка/Файл | Описание |
|------------|----------|
| `app.py` | Основное веб-приложение |
| `.gitignore` | Игнорируемые файлы Git |
| `pyproject.toml` | Зависимости Poetry |
| `poetry.lock` | Фиксация версий |
| `static/css/custom.css` | Пользовательские стили |
| `templates/index.html` | Главная страница |
| `templates/catalog.html` | Страница каталога |
| `templates/category.html` | Страница категории |
| `templates/contacts.html` | Страница контактов |


## 🌐 Доступные маршруты

| Страница | URL | Описание |
|----------|-----|----------|
| **Главная** | `/` | Welcome-страница магазина |
| **Каталог** | `/catalog` | Сетка товаров с фильтрами |
| **Категория** | `/category` | Детальная страница категории |
| **Контакты** | `/contacts` | Контактная информация и форма |

## 🛠 Технологический стек

- **Backend**: Python 3.13, стандартная библиотека (`http.server`)
- **Frontend**: HTML5, CSS3, Bootstrap 5.3 (CDN)
- **Стилизация**: Custom CSS
- **Шаблоны**: Чистый HTML
- **Управление**: Poetry (опционально)
